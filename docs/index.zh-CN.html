工作原理

截图与演示视频即将补充。下述链路已端到端跑通。

🎙️

1. 按住说话

按住全局热键（默认右 Option）自然说话；200ms 确认期防误触。

🔒

2. 本地转写

松手后由 WhisperKit small 端侧转写——音频仅存内存、不落盘。

✨

3. 润色

用你自己的 LLM Key 把转写润色成干净的工程 Prompt，带防脑补硬约束。

📋

4. 注入

结果落到你按下热键时正在使用的 App 光标处——剪贴板 + Cmd+V，带恢复与竞争保护。

🤖 100% AI 构建

本项目完全由 AI 编程助手构建。 每一行代码都是通过 AI 协作生成、审查和优化的。

功能特性

🎙️

按住说话全局热键

默认右 Option，200ms 防误触确认、300ms 误触取消、Esc 放弃。预设：右 Option / 右 Command / 右 Shift / Fn。

🔒

本地隐私转写

WhisperKit small 完全端侧运行，支持中英混合；模型就绪前由 Speech 框架兜底。

✨

LLM 润色

去口水词、句式规范化、结合上下文指代消解；超时回退原文——自备 Key。

🎯

上下文感知注入

按下时快照前台 App 与窗口标题，松手时二次校验，分类终端 / 编辑器 / 浏览器 / 其他。

📋

剪贴板 + Cmd+V

剪贴板快照/恢复 + changeCount 竞争保护；可选自动回车；CLI 目标折叠换行。

🪟

非激活 HUD

波形、阶段状态与成败反馈——全屏、多 Space 可见，不抢焦点。

🛡️

权限自检

引导式 onboarding + 系统设置深链；麦克风 / 输入监控 / 辅助功能缺失时优雅降级。

🩺

诊断日志

分类 os_log + 落盘日志，设置页一键导出。
