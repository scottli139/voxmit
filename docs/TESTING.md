# Voxmit 测试要求

> 本文档定义测试策略与质量门禁的工程化细节。需求层面的测试范围见 `语音编程工具-需求分析与方案说明.md` §9.3；两者冲突时以需求文档为准，并回改本文档。

## 测试金字塔

| 层 | 工具 | 范围 | 运行环境 |
|---|---|---|---|
| 单元测试 | Swift Testing（Xcode 16 原生） | 核心逻辑：状态机、润色回退、注入决策、上下文打包、剪贴板恢复、纯函数 | 本地 / CI，**无系统权限** |
| 集成 / 系统测试 | 真机手动（本文档清单） | 权限、热键、音频设备热切换、目标 App 注入矩阵 | 本机，逐项授权 |
| 验收测试 | 手动实测 + 日志计时 | 端到端延迟 P95、Prompt 可用率统计 | 本机 |

## 质量门禁

- 核心逻辑模块（VoicePipeline / PromptRefiner / Injector 决策 / ContextCollector）语句覆盖率 **≥ 80%**；
- CI：编译 + 全部单测 + SwiftLint 通过才允许合并；
- 主链路（热键 → 录音 → 转写 → 润色 → 注入）任何改动必须附手动测试执行记录。

## 单元测试规范

- 框架：**Swift Testing**（`@Test` / `#expect`）；若工程建立时选择 XCTest，以实际选择为准并更新本节；
- 可测性：模块协议见需求文档 §9.1；单测通过 mock 协议注入依赖，**禁止在单测中触发真实系统权限弹窗**；
- mock 集中管理：`VoxmitTests/Mocks/`（MockTranscriptionEngine / MockRefiner / MockInjector / MockClock 等）；
- 命名：`被测行为_场景_期望`，如 `hotkeyDown_shortPress_ignored`；
- MVP 必测清单：
  - **状态机**：短按（<200ms）忽略 / 录音 <300ms 误触取消 / Esc 取消 / 5 分钟自动结束 / 转写失败 / 润色失败回退后的注入路径；
  - **PromptRefiner**：3s 超时回退 / 快速重试 1 次 / 旁路修饰键 / 未配 Key 直出 / 上下文 2KB 截断；
  - **Injector**：无辅助功能权限 → `clipboardOnly` / 目标不可编辑降级 / 剪贴板保存与恢复 / `changeCount` 竞争时放弃恢复 / CLI 目标换行折叠；
  - **ContextCollector**：bundleID 分类表 / 无 AX 权限降级 / 松手时前台校验；
  - **纯函数**：文本截断、静音前缀裁剪、电平换算。

## 真机手动测试矩阵

> 系统交互无法自动化，按本清单执行并在 PR 中勾选；**每次发版前全量过一遍**。

### 目标 App 注入矩阵

- [ ] Terminal：光标处插入、不覆盖已有输入、多行折叠生效、自动发送开 / 关两种行为
- [ ] iTerm2：同上
- [ ] VS Code：同上
- [ ] Cursor：同上
- [ ] Safari 地址栏：注入可用
- [ ] 备忘录等原生 App：注入可用

### 权限路径

- [ ] 麦克风拒绝：无法录音，引导与错误提示正确
- [ ] 输入监控拒绝：热键失效，菜单栏点击降级路径可用
- [ ] 辅助功能拒绝：仅写剪贴板 + HUD 提示手动粘贴
- [ ] 运行中撤销权限：注入前检查发现并降级；event tap 自动恢复；自检页状态刷新

### 设备与边界

- [ ] 内置麦 ↔ 蓝牙麦 ↔ 2.4G dongle 热插拔；录音中断开回落系统默认设备，已录部分保留
- [ ] 密码框聚焦时按热键无反应（系统行为，不报错、不提示）
- [ ] 全屏终端中 HUD 可见；多显示器 / 多 Space
- [ ] 录音中 Cmd+Tab 切换 App：注入到松手时的前台 App
- [ ] 5 分钟上限：自动结束并继续处理已录部分
- [ ] 蓝牙麦刚连接的开头静音不进入转写结果

## 性能验收方法

- 在 VoicePipeline 各阶段边界打点时间戳（`os_log`，仅 debug 配置）：松手 → 转写完成 → 润色完成 → 注入完成；
- 采样：20 次 15 秒语音，取 P95 端到端延迟，对照需求文档 §1.3 预算表（≤ 2s）；
- 常驻内存与空闲 CPU 用 Activity Monitor 观测，指标见需求文档 §3.2；
- 润色可用率：内部试用积累 100 条，统计"无需手工修改直接发送"的比例（目标 ≥ 80%）。

## CI 规划

- GitHub Actions macOS runner：`xcodebuild build` + `xcodebuild test` + SwiftLint；
- 签名证书 / 公证凭据存 GitHub Secrets，**禁止入库**；CI 构建使用未签名配置；
- 覆盖率报告（`xcresulttool` 导出，或接 Codecov），随工程建立时选型落地；
- 发布 workflow（tag 触发：签名 → 公证 → DMG → Release）在首个版本发布前再建。
