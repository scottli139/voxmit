# Voxmit 使用说明

> 本文档面向最终用户，随开发进度持续更新：**每次提交涉及用户可见行为变化时，顺手更新本文档**（约定见 `CONTRIBUTING.md`）。
> 各小节标注实现状态：✅ 已可用 / 🚧 开发中（对应 `PLAN.md` 任务）。只描述已验证的行为，🚧 小节为功能预告。

## 1. 这是什么

Voxmit 是一款 macOS 菜单栏常驻的语音驱动 AI 编程工具：按住全局热键（默认右 Option）说话，松开后自动完成本地语音转写、LLM 润色，把高质量工程 Prompt 注入当前 AI 开发工具（Kimi Code / Claude Code / Cursor 等）的输入框。

它不做通用语音输入，只做"面向 AI 编程的语音入口"。

## 2. 系统要求

- macOS 14 Sonoma 及以上；推荐 Apple Silicon（Intel 机型将降级为云端转写 🚧）
- 当前无安装包，需从源码构建（见 §3）；正式发布后将提供签名 + 公证的 dmg（见 `PLAN.md` Phase 5）

## 3. 安装与启动 🚧

当前阶段（Phase 0/1）仅支持源码构建，面向开发者：

```bash
git clone https://github.com/scottli139/voxmit.git
cd voxmit
open Voxmit.xcodeproj   # 依赖（WhisperKit 等）由 Xcode 自动解析
```

用 Xcode 运行 `Voxmit` scheme。应用无 Dock 图标、无主窗口，启动后驻留菜单栏。

## 4. 权限设置 ✅

Voxmit 需要三项系统权限；缺失时会降级运行而不是崩溃：

| 权限 | 用途 | 没有它会怎样 |
|---|---|---|
| 麦克风（必需） | 录音 | 无法录音，核心功能不可用 |
| 输入监控（必需） | 全局热键（按住右 Option 说话） | 热键失效，可改用菜单栏点击开始/停止录音 |
| 辅助功能（可选） | 读取上下文、把文字注入输入框 | 注入降级为"复制到剪贴板"，需手动 Cmd+V 粘贴 |

**首次启动**时，若权限未集齐，会自动弹出「权限设置」窗口，按"麦克风 → 输入监控 → 辅助功能"顺序逐项引导：

- 每项右侧有「打开系统设置」按钮，直达系统设置的对应面板（隐私与安全性 → 麦克风 / 输入监控 / 辅助功能）；
- 麦克风在尚未请求过授权时，也可直接点「请求授权」弹出系统授权框；
- 窗口打开期间状态每秒自动刷新——在系统设置里打开开关后回到窗口，即可看到变为"已授权"；
- 三项全部就绪后点「完成」；辅助功能可点「跳过，降级运行」，日后再补授权（补上后注入体验更好）。

日常使用：菜单栏菜单的「权限自检…」可随时重新打开该窗口；权限未集齐时，菜单会显示缺失提示（如"⚠️ 权限未集齐：输入监控"）。若在系统设置中运行中途撤销了权限，重新打开权限自检页即可看到最新状态。

**另：语音识别权限**——当 WhisperKit 本地模型尚未下载完成、由系统 Speech 兜底转写时，首次使用会另行请求「语音识别」权限（与麦克风独立；仅端侧识别，音频不出本机）。本地模型就绪后默认不再使用 Speech。

## 5. 功能使用

### 5.1 菜单栏图标 ✅

启动后菜单栏出现 Voxmit 图标，点击展开菜单。当前菜单内容：

- 主链路状态（空闲 / 录音中 / 转写中 等，随 Phase 2 起逐步生效）；
- 「权限自检…」：打开权限设置窗口（见 §4）；权限未集齐时菜单顶部显示缺失提示；
- 无输入监控权限时，显示「开始录音 / 停止录音（菜单栏入口）」降级项，点击驱动与热键相同的状态机；无麦克风权限时该项禁用；
- 「设置…」（`Cmd+,`）与「退出 Voxmit」（`Cmd+Q`）。

### 5.2 设置页 ✅

菜单栏图标 →「设置…」（或 `Cmd+,`）打开设置页。当前可配置项：

- **热键**：按住说话的热键预设四档 ✅（右 Option / 右 Command / 右 Shift / Fn（Globe），默认右 Option，改动即时生效）、旁路修饰键（按住它说话可跳过 LLM 润色；热键为右 Shift 时旁路判定自动禁用）；完整自定义录入（任意组合键）🚧 V1.1
- **音频**：输入设备选择 ✅（系统默认 / 当前已连接的麦克风列表，下次录音生效）、提示音开关 🚧（V1.1）
- **转写**：引擎选择 ✅（WhisperKit 本地 / Speech 系统兜底，按模型就绪状态自动切换；云端 🚧 V1.1）、模型规格（tiny / small / large-v3，默认 small）、自定义热词词表 🚧（V1.1）；本地模型状态与下载进度（small 约 500MB，后台下载、可断点续传）实时显示，失败可重试
- **润色**：OpenAI 兼容端点（默认 Kimi/Moonshot：`https://api.moonshot.cn/v1`）、模型名（默认 `moonshot-v1-8k`）、API Key、润色开关
- **注入**：注入后自动回车发送、多行折叠为单行 🚧
- **诊断** ✅：「导出诊断日志…」——导出最近 24 小时的应用日志 + 环境信息快照（版本/macOS/机型/关键设置/四项权限状态）为单个文本文件，供问题排查；不含 API Key、转写内容等隐私数据
- **历史记录**：保留条数（默认 500）、保留天数（默认 30）🚧
- **通用**：开机启动 🚧

**API Key 只存系统钥匙串（Keychain）**，不会写入任何配置文件；设置其余项存于本机 UserDefaults。

### 5.3 按住说话 ✅

**当前进度（Phase 5）**：热键交互、状态机、音频采集、录音浮层（HUD）与本地转写已就绪——松手后完成真实语音转写（本地模型未下载时由系统 Speech 兜底）；润色与自动注入在后续 Phase 接入。**当前转写原文会写入剪贴板**，浮层提示「已复制，Cmd+V 手动粘贴」（因润色未接入，附「未润色」角标）。

已可用的热键行为（需已授予「输入监控」权限，见 §4）：

- **按住右 Option 说话**：按住约 0.2 秒进入录音状态（菜单栏图标与浮层同步变化）；短于 0.2 秒的轻触整次忽略（防止切换输入法等误触）；
- **松开结束**：进入录音后不足 0.3 秒即松开视为误触，自动取消；超过则进入后续处理流程；
- **`Esc` 取消**：按住确认期 / 录音中 / 处理中，任意阶段按 Esc 放弃本次，不产生任何写入；
- **旁路修饰键**：按下右 Option 的瞬间 Shift 处于按住状态，则本次跳过 LLM 润色（润色 🚧 Phase 6）；
- **单次上限**：一次录音最长 5 分钟，到点自动按"松手"流程处理已录部分，浮层提示"已达最长录音时长"；
- **设备切换**：录音中途拔插麦克风不会中断，已录部分保留；在设置中指定的输入设备断开时自动回落系统默认设备并在浮层提示；
- **开头静音**：蓝牙麦刚连接时的开头空数据会在转写前自动裁掉；
- **出错可见**：麦克风权限被拒或未检测到输入设备时，浮层与菜单栏状态会显示对应失败原因。

**录音浮层（HUD）**：录音时屏幕底部中央浮现胶囊状浮层——不抢键盘焦点（可继续在目标 App 中操作），全屏 App 与多桌面下均可见。

- 录音中：红色实时波形 + 「正在录音」+ 注入目标 App 名（目标识别 🚧 Phase 7，当前为占位显示）；
- 处理中：依次显示「转写中… / 润色中… / 注入中…」；
- 成功：绿色对勾「已注入」，约 1 秒自动淡出；若本次未经润色（回退或旁路），附「未润色」角标；
- 降级（无辅助功能权限等）：「已复制，Cmd+V 手动粘贴」，停留约 2.5 秒；
- 失败：显示原因，停留约 2.5 秒；取消则立即消失。

无「输入监控」权限时（降级模式）：菜单栏菜单提供「开始录音 / 停止录音」点击入口，与热键走同一套状态机；无「麦克风」权限时该入口禁用。在系统设置中补上输入监控权限后，热键自动生效，无需重启。

> 润色（Phase 6）、注入（Phase 8）接入后，松手 2 秒内润色后的 Prompt 会出现在当前 AI 工具的输入框光标处。

### 5.4 历史记录 🚧

每次转写/润色结果保存在本机 SQLite（明文，仅当前用户可读目录），按"30 天 / 500 条"滚动清理，设置页可一键清空。

## 6. 常见问题（FAQ）

随真机测试与用户反馈持续补充。

- **Q: 录音内容会被上传吗？** A: 默认不会。转写在本地完成（WhisperKit）；只有"润色"一步会把转写文本发给你自己配置的 LLM 端点，且可在设置中整体关闭。
- **Q: 录音文件保存在哪？** A: 不保存。录音只存内存，处理完即释放。
- **Q: 热键与其他 App（如微信语音输入）的快捷键冲突怎么办？** A: 设置页「热键」换成右 Command / 右 Shift / Fn 预设即可，即时生效；因冲突干扰导致的热键失灵会自动恢复（约 5 秒内），无需重启。
- **Q: 本地模型下载失败/超时怎么办？** A: 网络无法访问 huggingface.co 时会自动回退 hf-mirror.com 镜像重试一次（失败信息会注明两个端点），仍失败可在设置页「转写」区点「重试」继续（断点续传，不从头下载）。强制指定端点（无界面，默认 auto）：`defaults write com.voxmit.app asr.modelRepoEndpoint -string hf-mirror`（可选 huggingface / auto）。
- **Q: Speech 兜底转写失败提示听写相关？** A: 系统 Speech 兜底引擎依赖 macOS 的「听写」服务：请在 系统设置 → 键盘 → 听写 中开启（与语音识别权限是两回事）；**识别中文还需在 听写 → 语言 中添加「中文（普通话）」**。兜底默认按中文识别；如需改为英文等，可执行 `defaults write com.voxmit.app asr.speechLocale -string en-US`（无界面，默认 zh-CN）。WhisperKit 本地模型下载完成后默认不再使用 Speech，不受此限。
- **Q: WhisperKit 把中文识别成英文怎么办？** A: 短音频（尤其重复音节）自动语言检测不可靠，当前版本已默认锁定中文识别（中英文混说不受影响，纯英文也能正常转）。如需恢复自动检测：`defaults write com.voxmit.app asr.whisperLanguage -string auto`（无界面，默认 zh）。
- **Q: 如何查看诊断日志？** A: 三个途径——① 设置页「诊断」区点「导出诊断日志…」导出文件（推荐，发给开发者排查）；② 日志同时写在本地 `~/Library/Application Support/Voxmit/Logs/`（按日滚动，保留最近 7 个文件），可直接用文本编辑器阅读；③ 系统工具：Console.app 过滤 subsystem `com.voxmit.app`，或 `log show --predicate 'subsystem == "com.voxmit.app"' --last 1h`（实时跟踪换成 `log stream`）。
- **Q: 系统设置里权限开关已打开，自检页仍显示"未授权"？** A: 先完全退出 Voxmit 再启动（授权结果有进程内缓存）。仍不行时（开发构建常见）：在系统设置中把 Voxmit 从该权限列表"−"移除，终端执行 `tccutil reset Accessibility com.voxmit.app`（辅助功能为例），再用"+"重新添加当前 App 并打开开关，重启 App。开发构建每次重新编译后授权可能失效，需重做一次。
